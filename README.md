# KenHi Homestay Huế

Website đa trang cho **KenHi Homestay** (BGI Topaz Downtown, Hoàng Quốc Việt, P. An Cựu, TP. Huế).

## Cấu trúc dự án

- `index.html` — Trang chủ (Hero, Marquee ưu đãi đặt trực tiếp, Giới thiệu, Lý do chọn KenHi, Bảng phòng & Tạm tính + Giữ phòng nhanh qua Zalo, Đánh giá 5 sao, Cẩm nang Huế, Liên hệ & Bản đồ)
- `khong-gian.html` — Không gian thực tế (Parallax Carousel 3:4 & Lightbox hỗ trợ thumbnail + zoom/pan)
- `chuyen-cua-kenhi.html` — Câu chuyện thương hiệu & Giá trị cốt lõi
- `cam-nang.html` — Danh mục Cẩm nang Huế kèm tìm kiếm trực tiếp
- `bai-viet.html` — Trang chi tiết bài viết
- `posts.js` — Dữ liệu 5 bài viết Cẩm nang Huế
- `styles.css` — Hệ thống giao diện Swiss Minimalist & Responsive
- `script.js` — Tương tác trang, Parallax Carousel, Lightbox, Reviews Carousel, Estimator & VI/EN

## Xem trước cục bộ (Local Preview)

```bash
python -m http.server 8765
```

Mở trình duyệt tại `http://localhost:8765`.
